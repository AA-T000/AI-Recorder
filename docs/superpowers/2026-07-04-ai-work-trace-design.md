# AI 工作轨迹记录与日报生成器 — 设计文档

> 日期: 2026-07-04
> 状态: 初版设计

## 1. 项目概述

一个 Python 后台工具，自动记录用户在电脑上做什么（窗口切换、应用使用时长），在一天结束时通过 AI 生成结构化日报，回答两个核心问题：
- **今天我到底做了什么？**（时间线还原）
- **什么是时间黑洞？**（效率分析）

## 2. 核心设计原则

1. **隐私优先**：数据本地存储，不上传原始日志，只上传脱敏统计摘要
2. **模块化**：数据采集、分析、报告三个模块独立，可替换、可扩展
3. **渐进式**：从命令行工具起步，预留 GUI/App 扩展点
4. **开源友好**：代码结构清晰，文档完整，任何人都能审查

## 3. 技术选型

| 层级 | 技术 | 理由 |
|------|------|------|
| 语言 | Python 3.10+ | 跨平台、生态丰富、适合学习 |
| 数据采集 | `pygetwindow` + `psutil` | 获取前台窗口信息 |
| 数据存储 | SQLite (内置) | 零配置、便携、SQL 兼容 |
| 分析引擎 | 纯 Python | 无外部依赖 |
| AI 报告 | Agnes API (Claude Agent 兼容接口) | 用户已有配置 |
| 日报格式 | Markdown + HTML | 通用、可预览 |
| 系统托盘 | `pystray` | 轻量后台运行 |

## 5. 数据流

```
[窗口采样] → [SQLite 日志表] → [按日聚合] → [分析结果] → [Agnes API] → [日报]
   ↓                                                              ↓
  隐私保护                                           Markdown + HTML 输出
  (不上传原始日志)
```

## 6. 核心功能详述

### 6.1 数据采集 (recorder.py)

- 每 5 秒采样一次当前活动窗口
- 记录：应用名、窗口标题、时间戳
- 智能合并：相同窗口标题连续出现时不重复写入
- 异常处理：窗口获取失败时跳过，不中断程序

### 6.2 本地分析 (analyzer.py)

#### 时间线重建
- 将原始日志按时间顺序分组为「时间段块」
- 每个块代表一次连续的活动（如「10:00-10:45 VS Code」）

#### 应用分类
- 内置规则库：开发工具、浏览器、通讯、设计、办公等
- 可自定义分类映射（通过配置文件）

#### 时间黑洞检测
检测三种模式：
1. **碎片化切换**：5 分钟内切换 ≥3 个不同应用 → 注意力分散
2. **无意识摸鱼**：非预期时间段出现在娱乐/社交应用 → 时间浪费
3. **会议陷阱**：视频会议应用连续使用 >60 分钟 → 标注为深度会议日

#### 效率评分
- 基于专注时长占比、碎片化次数、时间黑洞数量计算 0-100 分

### 6.3 AI 日报生成 (reporter.py)

- 将本地分析结果（JSON 格式）发送给 Agnes API
- Prompt 模板要求返回：
  - 今日工作清单（按时间顺序）
  - 时间分布统计
  - 时间黑洞报告
  - 效率评分与建议
- 支持自定义 prompt 模板（通过配置文件）

### 6.4 日报输出

#### Markdown 格式
- 保存到 `~/Documents/AI-Recorder/reports/YYYY-MM-DD.md`
- 可直接查看或转发

#### HTML 仪表盘
- 交互式时间线视图
- 应用使用时长饼图数据
- 本周趋势折线图数据
- 时间黑洞标记

## 7. 隐私保护机制

1. **数据本地化**：所有原始日志存储在本地 SQLite
2. **脱敏上传**：只向 API 发送统计摘要，不包含窗口标题原文
3. **用户控制**：`settings.yaml` 中可开关数据采集项
4. **一键清除**：`ai-recorder clear` 命令删除所有数据
5. **开源审计**：代码完全公开，无隐藏行为

## 8. 扩展预留

- 键盘快捷键捕获（通过 `pynput`，可选）
- 剪贴板历史（可选，默认关闭）
- 文件访问记录（可选，默认关闭）

- **多设备同步**：预留云端同步接口（可选）

### 8.3 未来 AI 增强
- 周报/月报自动生成
- 项目工时统计
- 与项目管理工具集成（Jira、GitHub Issues）

## 9. 配置示例 (settings.yaml)

```yaml
recorder:
  sample_interval: 5        # 采样间隔(秒)
  upload_raw_logs: false     # 是否上传原始日志(始终false)
  privacy_mode: true         # 隐私模式：脱敏后上传

ai:
  api_base: "http://localhost:xxxx"   # Agnes API 地址
  api_key: "your-key"
  model: "agnes-xxx"
  prompt_template: "daily_report"

categories:
  development: ["code", "vscode", "pycharm", "idea"]
  browser: ["chrome", "edge", "firefox", "browser"]
  communication: ["wechat", "dingtalk", "teams", "zoom"]
  design: ["photoshop", "premiere", "figma", "sketch"]
  office: ["word", "excel", "powerpoint", "wps"]

blackhole:
  fragment_threshold: 3      # 5分钟内切换N次算碎片化
  focus_block_minutes: 20    # 连续专注最低时长(分钟)
```
